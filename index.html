Добро пожаловать в Nova AI

Ваш ИИ-ассистент: чат, фото, музыка, голос и поиск в интернете.

🧪 Приложение пока в бета-версии: возможны ошибки. Скоро появится служба поддержки.

Листайте дальше: покажем, как подключить ИИ — бесплатно или на полную мощность. В конце — правила и соглашение.

🆓 Бесплатно: через Puter

Самый простой способ, ключи не нужны.

  1. Откройте Настройки → ИИ и ключи.
  2. Нажмите «Войти в Puter» и зарегистрируйтесь (бесплатно).
  3. Выберите «Сначала Puter, потом ключи».
Ответы идут из бесплатной месячной квоты вашего аккаунта Puter. Когда она кончится, Nova сама переключится на ваши ключи (если они добавлены).

🚀 Мощнее: свой ключ Gemini

Даёт самые умные ответы, разбор фото и видео.

  1. Включите VPN.
  2. Откройте aistudio.google.com/app/apikey → Create API key → скопируйте ключ (начинается с AIza).
  3. В Nova: Настройки → ИИ и ключи → вставьте ключ → «Сохранить ключ».
  4. Теперь VPN можно выключить — но только если настроен прокси (следующая страница). Без прокси Gemini из России без VPN может не открываться.

🔌 Прокси: Gemini без VPN

Бесплатный мини-сервер на Cloudflare, делается один раз:

  1. dash.cloudflare.com → регистрация (карта не нужна).
  2. Workers & Pages → Create → Create Worker → Deploy → Edit code → удалите весь код.
  3. В Nova: Настройки → ИИ и ключи → «Скопировать код прокси», вставьте в Cloudflare → Deploy.
  4. Адрес вида https://имя.логин.workers.dev вставьте в поле «Адрес прокси» → «Сохранить адрес» → «Проверить прокси».
Подробная инструкция есть в Настройках → ИИ и ключи, пункт 4.

Что здесь нужно

Чтобы приложение работало, достаточно одного ключа Gemini. Всё остальное делает его лучше, но не обязательно. Ниже — по порядку, что это даёт и как получить.

1. Gemini — главный ключ

Обязательно. Нужен для Nova Lite, Nova Pro, разбора фото и видео. Бесплатно.
  1. Откройте aistudio.google.com/app/apikey (нужен аккаунт Google).
  2. Нажмите Create API key.
  3. Скопируйте ключ (он начинается с AIza).
  4. Вставьте его ниже и нажмите «Сохранить ключ».

2. Tavily — поиск в интернете

По желанию. Без ключа режим «Интернет» ищет только по Википедии. С ключом — по всему вебу, 1000 запросов в месяц бесплатно.
  1. Откройте tavily.com → Sign Up (можно через Google).
  2. Ключ сразу виден на главном экране кабинета, он начинается с tvly-.
  3. Вставьте ниже и сохраните.

3. ACE Music — создание музыкибесплатно

По желанию. Нужен только для создания музыки: кнопка «+» → «Создать музыку». Без этого ключа всё остальное работает как обычно. Сервис делает песни со словами и инструментальную музыку по вашему описанию, готовый трек можно скачать в MP3.
  1. Откройте acemusic.ai и зарегистрируйтесь (бесплатно).
  2. Откройте раздел API Key (адрес acemusic.ai/api-key) и создайте ключ.
  3. Скопируйте ключ, вставьте ниже и нажмите «Сохранить ключ».

4. Прокси — один на всё

По желанию. Прокси — это ваш личный бесплатный мини-сервер на Cloudflare. Он один и делает сразу три дела:
• Gemini работает без VPN (если Google у вас не открывается);
• фото создаются лучше: моделями FLUX.2 вместо обычного режима;
• музыка создаётся надёжнее: запросы к ACE Music тоже идут через него.
Если Gemini у вас и так работает, а обычные фото устраивают — этот пункт можно пропустить.
Часть А. Создать прокси (5 минут, один раз)
  1. Откройте dash.cloudflare.com и зарегистрируйтесь (бесплатно, карта не нужна).
  2. Слева выберите Workers & Pages → Create → Create Worker. Имя любое. Нажмите Deploy.
  3. Нажмите Edit code, выделите весь код (Ctrl+A) и удалите его — поле должно стать пустым. (Если прокси у вас уже есть, просто замените его код на новый.)
  4. Вернитесь сюда, нажмите кнопку «Скопировать код прокси», вставьте его в Cloudflare и нажмите Deploy.
  5. Скопируйте адрес вашего Worker (вида https://имя.логин.workers.dev) и вставьте в поле «Адрес прокси» ниже.
Часть Б. Включить фото (1 минута, по желанию)
  1. В Cloudflare откройте ваш Worker → Settings → Bindings → Add → Workers AI.
  2. В поле «Variable name» напишите большими буквами AI и сохраните.
Без части Б прокси всё равно работает для Gemini, а фото создаются обычным способом.

Усилие размышления

Насколько сильно модель думает, проверяет и сверяется перед ответом. Чем выше усилие, тем умнее и аккуратнее ответ, но он приходит дольше. У Nova Lite доступно до «Высокого», «Максимум» — только у Nova Pro. В режиме «Авто» совсем короткие простые вопросы Lite отвечает без размышления. Рекомендуем среднее.
